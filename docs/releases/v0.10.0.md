# Nukify 0.10.0 — GENAI Studio

[English](#english) · [Español](#español)

## English

Windows x64 technical beta by **Max Sarlija**, with **Blender 4.5.14 LTS included**.

### New: GENAI Studio powered by fal.ai

Open **GENAI** in the main toolbar. Use your own **fal.ai API key and billing account** to generate/edit images and videos, including image-to-video. The key is kept in session memory or read from `FAL_KEY`; it is not saved in project or job files.

- 11 featured endpoints across Nano Banana 2.1/Pro, GPT Image 2, MiniMax H3 Max and Kling 4/O3 Pro; live catalog search and schema refresh.
- Model-specific quality, resolution, duration, format, seed and reference controls.
- Queue/process tracking, resumable request IDs, downloaded originals, local proxies and a versioned media library.
- Import images or extracted video sequences into the compositor as `Read` nodes.
- Price estimates from fal based on **manually entered billing units**, followed by confirmation before upload and paid submission. Quality/duration multipliers are not applied automatically; the estimate is not a guaranteed final charge or a spending cap.
- Main README in English, Spanish option, bilingual release notes and actual UI screenshots.

![Actual GENAI Studio interface / Interfaz real de GENAI Studio](https://raw.githubusercontent.com/maxsarlijagit/Nukify/main/docs/images/genai.png)

### Downloads and setup

- **Nukify-Setup-0.10.0.exe:** complete Windows installer; no separate Python or Blender required.
- **Nukify-0.10.0-source.zip:** Nukify source, documentation and screenshots.
- **Upstream sources:** Blender, Qt and PySide/Shiboken sources are included in the installer. They are unchanged from 0.9.2 and are also available in the [existing source archive](https://github.com/maxsarlijagit/Nukify/releases/download/v0.9.2/Nukify-0.9.2-upstream-sources.zip).
- **SHA256SUMS.txt** and **VALIDATION.json:** checksums and validation evidence.

For video proxies and frame extraction, install FFmpeg separately and configure it in **GENAI → Conexión** or PATH. FFmpeg is not bundled. Existing compositing examples remain under **Proyecto → Ejemplos**.

### Validation and limits

67 local tests passed with Blender configured. Five packaged-executable suites passed: offline GENAI, expressions/roto, A/B caching, rendering/queue/media and compositing/tracking/EXR regression. The GENAI packaged test used synthetic local media with network calls blocked. Public fal catalog/schema queries were verified; **paid inference has not been tested with a real account**.

This remains a technical beta. Real-footage/artist acceptance and a full installation on a second clean PC are pending. The installer is not commercially code-signed. Playback depends on cache and graph cost. Pausing local tracking does not cancel remote execution or billing; cancellation may not stop a running job.

## Español

Beta técnica para Windows x64 de **Max Sarlija**, con **Blender 4.5.14 LTS incluido**.

### Nuevo: GENAI Studio con fal.ai

Abrí **GENAI** en la barra principal. Usá tu propia **API key y cuenta de facturación de fal.ai** para generar/editar imágenes y videos, incluyendo imagen a video. La clave queda en memoria durante la sesión o se toma de `FAL_KEY`; no se guarda en proyectos ni trabajos.

- 11 endpoints destacados de Nano Banana 2.1/Pro, GPT Image 2, MiniMax H3 Max y Kling 4/O3 Pro; búsqueda de catálogo y actualización de schemas.
- Controles de calidad, resolución, duración, formato, seed y referencias según el modelo.
- Seguimiento de cola/proceso, recuperación por request ID, originales descargados, proxies locales y biblioteca versionada.
- Importación al compositor mediante nodos `Read`, con extracción de secuencias para video.
- Estimación de precio de fal por **unidades facturables ingresadas manualmente**, con confirmación antes de subir medios y enviar una generación paga. No aplica automáticamente multiplicadores de calidad/duración ni garantiza un importe final o un tope de gasto.
- README principal en inglés, opción en español, notas de versión bilingües y capturas reales de interfaz.

### Descargas y configuración

- **Nukify-Setup-0.10.0.exe:** instalador completo para Windows; no requiere Python ni Blender aparte.
- **Nukify-0.10.0-source.zip:** código propio, documentación y capturas.
- **Fuentes externas:** el instalador incluye las fuentes de Blender, Qt y PySide/Shiboken. No cambiaron respecto de 0.9.2 y también están disponibles en el [archivo de fuentes existente](https://github.com/maxsarlijagit/Nukify/releases/download/v0.9.2/Nukify-0.9.2-upstream-sources.zip).
- **SHA256SUMS.txt** y **VALIDATION.json:** checksums y evidencia de validación.

Para proxies y extracción de cuadros de video, instalá FFmpeg por separado y configuralo en **GENAI → Conexión** o en PATH. No viene incluido. Los ejemplos de composición siguen en **Proyecto → Ejemplos**.

### Validación y límites

67 pruebas locales aprobadas con Blender configurado. Cinco suites del ejecutable aprobadas: GENAI sin red, expresiones/roto, cache A/B, render/cola/medios y regresión de composición/tracking/EXR. La prueba empaquetada de GENAI usó medios sintéticos locales y bloqueó llamadas de red. Se verificaron las consultas públicas de catálogo/schema de fal; **no se probó inferencia paga con una cuenta real**.

Sigue siendo una beta técnica. Faltan aceptación con planos reales/artistas e instalación completa en una segunda PC limpia. El instalador no tiene firma comercial. La reproducción depende del cache y del grafo. Pausar el seguimiento local no cancela la ejecución ni los cargos remotos; la cancelación puede no detener un trabajo ya iniciado.
