# Nukify 0.11.0 — Updates and EXR layers / Actualizaciones y capas EXR

Standalone Windows x64 technical beta by **Max Sarlija**, licensed under GPL-3.0-or-later.
Includes Blender 4.5.14 LTS; no separate Python or Blender installation is required.

## Español

- Búsqueda automática de actualizaciones en GitHub en segundo plano, como máximo una vez cada 24 horas.
- Aviso con versión instalada, nueva versión y changelog. Permite descargar, posponer u omitir una versión.
- Menú **Proyecto → Actualizaciones** con búsqueda manual, consulta automática y canal beta opcional.
- Descarga del instalador con comprobación de tamaño y SHA256; instalación mediante clic explícito y asistente de Windows.
- El cierre para instalar respeta los proyectos sin guardar y los procesos activos.
- Versión del título obtenida del manifiesto del paquete.
- Corrección de EXR con canales `Source.red/green/blue`, selección de capas y alfa separado `Alpha.red`.

Instalá **Nukify-Setup-0.11.0.exe** para incorporar el actualizador por primera vez.
Las versiones anteriores no pueden detectar actualizaciones por sí mismas. Guardá tu proyecto
y cerrá Nukify antes de ejecutar el instalador. Verificá el archivo con **SHA256SUMS.txt**.

## English

- Background GitHub update checks, at most once every 24 hours.
- Update dialog with installed/new versions and release changelog; download, defer or skip a version.
- **Project → Updates** menu for manual checks, automatic-check preference and optional beta channel.
- Installer size and SHA256 verification; installation requires an explicit click and uses the Windows setup wizard.
- Unsaved projects and active jobs retain their existing close safeguards.
- Window title reads the version from the package manifest.
- Fixed EXR imports using `Source.red/green/blue`, named passes and separate `Alpha.red` channels.

Install **Nukify-Setup-0.11.0.exe** once to receive the updater. Earlier versions do not
include update checks. Save your project and close Nukify before running setup.
Verify the download against **SHA256SUMS.txt**.

## Validation and limits / Validación y límites

See **VALIDATION.json** for the executed release checks. Tests use controlled fixtures;
they do not establish production suitability for every media file or environment.
The updater's installer launch is tested without performing an unattended installation.
Installer is not commercially code-signed. Installation on a second clean PC remains pending.
GENAI tests use local fixtures and do not run paid inference. FFmpeg is not bundled.
