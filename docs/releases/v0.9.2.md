# Nukify 0.9.2 — First public beta / Primera beta pública

[English](#english) · [Español](#español)

## English

Open-source node-based compositor for Windows x64 by **Max Sarlija**, with **Blender 4.5.14 LTS included**. This is the first public beta; **GENAI is not included in 0.9.2**.

### Download

- **Nukify-Setup-0.9.2.exe:** complete installer; no external Python or Blender required.
- **Nukify-0.9.2-source.zip:** Nukify source, documentation and screenshots for this version.
- **Nukify-0.9.2-upstream-sources.zip:** original Blender, Qt base/SVG and PySide/Shiboken sources.
- **SHA256SUMS.txt:** published-file checksums.
- **VALIDATION.json:** packaged-binary validation and source commit.

### Included

Automatically updating viewer, A/B comparison and cached playback; vertical graph; adaptive UI with vector icons and parameter search; curves/expressions; roto and keying; assisted 2D/planar tracking; 3D nodes; EXR/Cryptomatte and a resumable render queue.

Try **Proyecto → Ejemplos → Composición** or **Curvas y roto**. Use **Espacio** to select a panel layout.

### Validation

46 local tests passed. GitHub Actions ran the 46-test suite with one OCIO test skipped because Blender's config was unavailable. Four packaged suites passed using the included engine: expressions/roto, A/B caching, render/queue/media and compositing/tracking/EXR regression.

Technical beta validated with synthetic fixtures. Real-shot/artist acceptance and testing on a second clean PC are pending. The installer is not commercially code-signed. Real-time playback depends on cache and graph cost.

## Español

Compositor nodal open source para Windows x64, creado por **Max Sarlija**, con **Blender 4.5.14 LTS incluido**. Primera beta pública; **GENAI no está incluido en 0.9.2**.

### Descargar

- **Nukify-Setup-0.9.2.exe:** instalador completo. No requiere Python ni Blender externos.
- **Nukify-0.9.2-source.zip:** código propio, documentación y capturas de esta versión.
- **Nukify-0.9.2-upstream-sources.zip:** fuentes originales de Blender, Qt base/SVG y PySide/Shiboken.
- **SHA256SUMS.txt:** hashes de los archivos publicados.
- **VALIDATION.json:** resultados de pruebas del binario y commit fuente.

### Incluye

Viewer con actualización automática, A/B y playback con cache; graph vertical; UI adaptable con iconos vectoriales y búsqueda de parámetros; curvas/expresiones; roto y keying; tracking 2D/planar asistido; nodos 3D; EXR/Cryptomatte y cola reanudable.

Probá **Proyecto → Ejemplos → Composición** o **Curvas y roto**. En **Espacio** se eligen las distribuciones de paneles.

### Validación

46 pruebas locales aprobadas. GitHub Actions ejecutó la suite de 46 pruebas, con una omitida por no disponer del config OCIO de Blender. Cuatro suites del ejecutable aprobadas con el motor incluido: expresiones/roto, cache A/B, renders/cola/medios y regresión de composición/tracking/EXR.

Beta técnica con fixtures sintéticos. Pendientes la aceptación con artistas/planos reales y una segunda PC limpia. Instalador sin firma comercial de código. El playback en tiempo real depende del cache y del grafo.
