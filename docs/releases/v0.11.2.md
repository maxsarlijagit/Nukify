# Nukify 0.11.2 · macOS Apple Silicon

This release adds a native macOS arm64 application and drag-to-Applications DMG. Windows users can continue using the existing Windows installer; this release does not provide a new Windows binary.

- Private Blender 4.5.14 LTS engine inside the application bundle.
- Platform-aware Blender, OCIO and isolated EXR Python paths.
- Portable shortcut serialization, shared between macOS and Windows presets.
- Updates select the matching architecture DMG and open it for manual replacement.
- Reproducible build script with a pinned official Blender DMG hash, source commit, original sources and dependency notices.
- Unit CI extended to Apple Silicon macOS as well as Windows.

Requires macOS 12+ and Apple Silicon. Ad-hoc signed; not Developer ID signed or notarized. Intel and installation on a second clean Mac remain unvalidated. See the macOS section of README and BUILDING for installation and validation commands. Detailed binary validation is distributed beside the assets.
