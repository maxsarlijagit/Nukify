# Nukify 0.10.1 — English / Español

[English](#english) · [Español](#español)

## English

Windows x64 technical beta by **Max Sarlija**, with **Blender 4.5.14 LTS included**.

- English is now the default interface language. Choose **Language / Idioma → English or Español**, save, and reopen Nukify.
- Language preferences persist independently of projects. Menus, viewer tools, inspector labels, dialogs and GENAI controls are translated; technical identifiers, provider schemas and user content remain unchanged.
- The node palette adapts to longer translated labels. Startup callbacks no longer access destroyed windows.
- GENAI Studio continues to support fal.ai with your own API key, explicit cost confirmation, local proxies and versioned results.

![English interface](https://raw.githubusercontent.com/maxsarlijagit/Nukify/v0.10.1/docs/images/interface-en.png)

### Downloads

**Nukify-Setup-0.10.1.exe** includes the application and Blender; no separate Python or Blender installation is required. **Nukify-0.10.1-source.zip**, **SHA256SUMS.txt** and **VALIDATION.json** provide source and verification evidence. Blender, Qt and PySide sources are included in the installer and are also available in the unchanged [upstream source archive](https://github.com/maxsarlijagit/Nukify/releases/download/v0.9.2/Nukify-0.9.2-upstream-sources.zip).

Validation: 73 local tests, five packaged regression suites and packaged language checks for English and Spanish. UI checked at 1024/1440 px and 100%/150% scaling. This remains a technical beta: paid fal inference and installation on a second clean PC have not been verified. FFmpeg for video proxies is configured separately; the installer is not commercially code-signed.

## Español

Beta técnica para Windows x64 de **Max Sarlija**, con **Blender 4.5.14 LTS incluido**.

- Inglés como idioma inicial. Elegí **Language / Idioma → English o Español**, guardá y volvé a abrir Nukify.
- La preferencia se conserva por separado de los proyectos. Se traducen menús, herramientas del viewer, etiquetas del inspector, diálogos y controles GENAI; los identificadores técnicos, schemas del proveedor y contenidos del usuario se conservan.
- La paleta de nodos se adapta a etiquetas traducidas más largas. Los callbacks de inicio ya no acceden a ventanas destruidas.
- GENAI Studio mantiene fal.ai con API key propia, confirmación explícita de costos, proxies locales y resultados versionados.
